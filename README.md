# 🐘 # PostgreSQL Studies

![](https://media.tenor.com/4CfIDNeonQwAAAAj/postgres.gif)

A repository for my **PostgreSQL** studies.

## About

I have already studied SQL in depth using **SQLite** (see the [SQL---Studies](https://github.com/d-almeidas/SQL---Studies) repository), where I practiced queries, aggregations, JOINs, CTEs, and window functions, and built a complete customer behavioral profiling project.

This repository **is not an SQL course starting from scratch**—it represents the migration of that knowledge to PostgreSQL, focusing on features specific to it: installation and connection to a real server, stricter data types, `SERIAL`/`BIGSERIAL`, constraints, date functions (`AGE`, `EXTRACT`), `ON CONFLICT`/`UPSERT`, actual foreign key implementation, and other features not found in SQLite.

## What's included here

Only what is **new** compared to what I already know about SQL:

- Syntax and data type differences compared to SQLite
- Constraints and keys (`PRIMARY KEY`, `UNIQUE`, `CHECK`, `FOREIGN KEY`)
- `SERIAL` / `BIGSERIAL` and sequences
- PostgreSQL date and time functions
- `ON CONFLICT` / `UPSERT`
- PostgreSQL-specific practical exercises
