# 🐘 # PostgreSQL Studies

![](https://media.tenor.com/4CfIDNeonQwAAAAj/postgres.gif)

Repositório com meus estudos de **PostgreSQL**.

## Sobre

Já estudei SQL a fundo usando **SQLite** (veja o repositório [SQL---Studies](https://github.com/d-almeidas/SQL---Studies)), onde pratiquei consultas, agregações, JOINs, CTEs, window functions e construí um projeto completo de perfil comportamental de clientes.

Este repositório **não é um curso de SQL do zero** — é a migração desse conhecimento para o PostgreSQL, focando no que é específico dele: instalação e conexão com um servidor de verdade, tipos de dados mais rígidos, `SERIAL`/`BIGSERIAL`, constraints, funções de data (`AGE`, `EXTRACT`), `ON CONFLICT`/`UPSERT`, foreign keys aplicadas de fato, e os demais recursos que o SQLite não tem.

## O que vai entrar aqui

Só o que for **novo** em relação ao que já sei de SQL:

- Diferenças de sintaxe e tipos de dado em relação ao SQLite
- Constraints e chaves (`PRIMARY KEY`, `UNIQUE`, `CHECK`, `FOREIGN KEY`)
- `SERIAL` / `BIGSERIAL` e sequences
- Funções de data e hora do PostgreSQL
- `ON CONFLICT` / `UPSERT`
- Exercícios práticos específicos do PostgreSQL
